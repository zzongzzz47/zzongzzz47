## 어디서부터 읽을까?

- **머신러닝을 처음 공부한다면:** 데이터 전처리와 교차 검증 → 분류 지표 → 결정 트리와 앙상블
- **신경망의 계산을 이해하고 싶다면:** 퍼셉트론 → 오차역전파 → 매개변수 갱신 → CNN
- **예측을 운영 의사결정에 연결하려면:** 시계열 기초 → 품목별 예측 → 안전재고와 매입량

## 기록의 구분

머신러닝 노트는 **IBAS 공동 스터디 자료**로 소개합니다. 딥러닝은 작성자를 확인할 수 있는 개인 노트를 중심으로 요약했습니다. 노션의 공유 권한은 변경하지 않았으며, 일부 원문은 로그인과 열람 권한이 필요합니다.

학습 기록은 개념을 이해하고 실습한 과정을 모은 것입니다. 개별 프로젝트의 구현 범위와 성과는 [프로필의 프로젝트 목록](../README.md)에서 해당 코드와 보고서로 확인할 수 있습니다.

## 앞으로 추가하는 방법
